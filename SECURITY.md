# Reporting a security problem in the Decision Provenance Standard&trade;

The Standard is a text and a set of machine-readable files, not a hosted service. A security problem here is anything that could let someone:

- forge, alter or silently drop records while still passing the Standard's checks or its seal;
- make the published schemas accept records they should reject, in a way that hides tampering; or
- tamper with the published downloads or their checksums.

**Please report these privately, not in a public issue.** Use the "Report a vulnerability" button on this repository's Security tab: https://github.com/decision-provenance-standard/standard/security/advisories/new

We will acknowledge your report, agree a fix with you, and credit you in the release notes in the form you approve.

Ordinary defects, such as typos, contradictions or wrong examples, belong in a normal issue.
